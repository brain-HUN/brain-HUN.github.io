gdoc-edit – privacy policy

gdoc-edit is a personal tool that I (akos.brain@gmail.com) use only with my own Google account.

Data accessed

With the permissions granted at sign-in (Google Docs, Google Drive read-only, and files created by the tool), it reads the Google Docs I select, applies the edits I make, and uploads images I choose.

How data is used and stored

Document content and the sign-in token are stored only on my own computer or in my own private development sessions. The data is used only to read and edit my own documents; it may be processed by tools I run myself, including an AI assistant, solely to carry out those edits. It is not sold, not shared with anyone else and not used for advertising.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
